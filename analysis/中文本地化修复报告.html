Wallpaper Changer v4.7.4 — 中文本地化修复报告

包名 de.j4velin.wallpaperChanger · 目标 SDK 25 · 修复对象：res/values-zh-*/strings.xml · 2026-10-20

!问题根因

应用在简体中文（zh-rCN）界面里同时出现了简体、繁体、英文三种文字，并非恶意，而是本地化资源错配：

现象原因
繁体混入简体values-zh-rCN 本应是纯简体，却直接写入了大量繁体词：資料夾 / 相簿 / 購買 / 刪除 / 贊助 / 聯繫 / 圖像 / 錯誤 等，与相邻的简体词并排显示。
英文回退zh-rCN 仅 64 条，而默认英文 values 有 173 条。缺少的键（如 muzei_desc、camera_not_found、create_folder_* 等 33 条）会回退成英文。
繁体不全zh-rHK 仅 39 条，Android 不会自动回退到 zh-rTW，香港用户也会看到英文。
编码 bugplease_wait 在 zh-rCN 中写成 稍等一下#8230;，实体未被解码，会原样显示 “#8230;”。

✓修复方案

以最完整的繁体文件 values-zh-rTW（121 条，译文准确）为权威源，用 OpenCC 把繁体统一转简体，补齐缺失键的双语译文，再把三个中文资源重写为各自完整、内部一致的版本：

文件修复后条数内容
values-zh-rCN149纯简体， mainland 用词归一（文件夹/设置/图标/应用程序/屏幕/文件/在线），无繁体、无英文回退。
values-zh-rTW149完整繁体，并修正原译文错误（下一個桌布管理器 → 下一張桌布，選擇桌布管理器 → 選擇桌布）。
values-zh-rHK149完整繁体，解决香港用户英文回退问题。
  • 新增 33 条此前完全没有中文翻译的键（来自英文默认），如 album_add_explain、camera_not_found、create_folder_*、muzei_desc、rule_permission_warning 等，现已全部翻译成中文。
  • 修正 please_wait 的 #8230; 实体错误 → 正确的省略号 “…” 。
  • 默认 values（英文）保持不变，作为非中文语言的合法回退。

⚙交付物与安装说明

  • 修正后的源资源：decode_out/res/values-zh-rCN|zh-rTW|zh-rHK/strings.xml，可直接二次编译或并入源码。
  • 生成脚本：generate_strings.py（OpenCC t2s + 手动补译，可复跑）。
